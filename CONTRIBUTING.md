# Contributing

Bug reports, accessibility improvements, UI refinements, and well-sourced calculation fixes are welcome. This is a free community project; contributions do not imply a paid support agreement.

For local setup and project structure, read `README.md`. Work on a branch. Before submitting code, run `pnpm test`, `pnpm lint`, and `pnpm build` from `app/`, and report any existing failures separately from changes you introduced.

For a calculation change, explain the input, expected result, current result, and a public manufacturer reference with document revision/page. Add a focused regression test when it verifies meaningful behavior. Do not submit proprietary manuals as attachments; link to authorized public documentation.

Do not submit decompiled source, proprietary installers or libraries, database dumps, extracted manufacturer tables, copied descriptions or images without permission, secrets, or real customer project files. Synthetic fixtures should contain invented customer information. For data and artwork, record source, date, permission/license, and modifications. Public availability alone does not establish redistribution permission.

Contributions of original work are offered under the project's MIT-0 license. You must have authority to contribute them. Third-party components retain their own terms and notices.

For a suspected exposed credential or private customer data, contact the repository owner privately through their GitHub profile before opening a public issue. Do not paste the sensitive value into an issue or pull request.
